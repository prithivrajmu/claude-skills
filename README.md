# claude-skills

An index of my Claude Code skills and slash commands. Each one lives in its own repo.

| Name | Type | What it does |
|---|---|---|
| [asd-ste100](https://github.com/prithivrajmu/asd-ste100) | Skill | Explains things in ASD-STE100 Simplified Technical English (80% mode by default). |
| [peer-pr-review](https://github.com/prithivrajmu/peer-pr-review) | Skill | Reviews a GitHub PR for policy, claim accuracy, Copilot status and DRY, in a subagent. Self mode requests Copilot, waits, and posts the findings on your own PR. |
| [pr-screenshots](https://github.com/prithivrajmu/pr-screenshots) | Skill | Captures one Playwright screenshot for each reachable UI state of a PR. |
| [verify-claims](https://github.com/prithivrajmu/verify-claims) | Command | Checks that a PR's claimed work is really done: Opus audits, Sonnet fixes, a fresh Opus re-audits. |

See each repo's README for install steps and notes.
